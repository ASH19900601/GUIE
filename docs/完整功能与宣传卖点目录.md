# GUIE 视觉小说创作工坊 — 完整功能与宣传卖点目录

> 本文档面向产品介绍、版本发布与同类工具对比，按完整能力维度梳理 GUIE 的全部产品特性与核心差异化卖点（已合并所有零散基础操作，确保每一条均为高价值完整能力项）。

---

## 核心差异化宣传卖点（Top 5 USP）

1. **真正面向零基础创作者的纯 GUI 全流程闭环**：断网、无 AI 即可 100% 通过图形界面完成角色、剧本、立绘、演出、复合条件分支、外观、扩展系统、问题修复、试玩与打包发布；严格隔离底层技术术语，绝不把代码与报错抛给创作者。
2. **双层智能 AI 创作助手（标准结构 + 源码兜底）**：普通剧本与分支生成 100% 可视化可编辑结构；遇到手机聊天系统、复杂背包、小游戏等定制玩法时，AI 直接在受保护扩展区编写并自动校验修复，后续改样式加功能只需再说一句自然语言。
3. **编辑、预览、时间轴调试一体化工作台**：告别“写几句 → 重启游戏从头跑”的割裂体验；右侧常驻 16:9 即时画面与实机镜像，卡片与画面双向定位，支持拖动时间轴回溯路线轨迹并实时拨动好感度/线索开关测试条件分支。
4. **内置 100% 离线语音识别（ASR）转剧本与语音匹配**：无需联网、无需安装外部命令行工具，软件内置神经网络语音识别模型，支持麦克风直录或批量导入音频文件离线转文字，校对后一键绑定到现有对白或批量生成带语音对白。
5. **安静克制的「纸张工作台」美学与军工级数据防丢失机制**：彻底告别廉价 AI 模板感与花哨杂乱界面；内置原子写入队列、输入草稿强制落盘屏障、全局撤销/重做与跨重启自动快照，确保灵感绝不丢失。
