# GUIE 视觉小说创作工坊 — 功能介绍大纲

## 一、 产品定位与核心理念

**GUIE** 是一款面向**零编程基础创作者**的可视化视觉小说（AVG / Galgame）桌面创作引擎，底层由成熟稳定的 **Ren'Py** 驱动，以**“纯 GUI 零代码全流程创作 + 内置 AI 全能编辑兜底 + 编辑器内即时预览与时间轴调试”**为核心产品定位。

### 双层零代码能力模型
- **第一层：纯 GUI 独立闭环（断网、无 AI 可 100% 独立完成）**
  覆盖从新建项目、角色与表情、多语言字体、对白与富文本、背景/立绘/镜头特效、音频与离线语音转剧本、复合条件分支与路线汇合、游戏外观与扩展系统，到自动检查修复、实机试玩与独立打包导出的完整创作闭环。
- **第二层：内置 AI 直接维护源码兜底**
  针对超出常规可视化表单范围的高级定制玩法（如自定义手机聊天系统、复杂背包、小游戏、特殊界面动效），创作者直接用自然语言指挥内置 AI 在受保护扩展空间编写、校验并持续修改，全程无需接触代码。

### 双模式渐进披露与术语隔离
- **默认创作模式**：界面严格使用创作者熟悉的自然语言概念（游戏、章节、场景、对白、旁白、角色、表情、背景、立绘、选择、分支、汇合、结局、故事状态、显示规则等），彻底隐藏底层脚本与工程术语。
- **可选高级模式**：面向熟悉开发的进阶用户，按需切换展示脚本文件树、代码编辑器与工程级诊断输出，并可随时安全返回创作模式。

## 二、 核心功能模块总览

| 模块 | 核心职责与用户价值 |
| :--- | :--- |
| **欢迎首页与项目初始化** | 编辑出版式双栏首页，零配置新建/打开项目，自动内置并维护支持中日韩（CJK）与拉丁/西里尔字符的开源字体，彻底告别缺字方框。 |
| **故事工作台（核心三栏）** | 左侧章节/场景大纲 + 中间「卡片剧本 / 纯文本剧本 / 选线流程图」三视图 + 右侧常驻「即时预览与时间轴调试器」，辅以按需滑出的添加内容抽屉。 |
| **即时预览与时间轴调试** | 修改即刻同步渲染；卡片与画面双向定位；可拖动步骤时间轴回溯路线轨迹与实时修改故事状态；支持真实引擎实机画面镜像与无循环热重载。 |
| **角色阵容与故事状态** | 阵容列表与聚焦详情分离；立绘批量拖拽按文件名自动建角与管理表情服装；独立标签页管理数字/开关/文字及跨周目持久故事状态。 |
| **素材管理中心** | 统一拖拽导入并自动分类，实时追踪全项目引用次数与可点击跳转的使用位置，自动标出丢失与游离素材，支持导出范围预测与一键全项目替换。 |
| **游戏外观实时定制** | 主题、字体、对话框、按钮、窗口五分类导航；高对比度可读预设；精细参数折叠与单分类重置；右侧常驻真实比例即时预览。 |
| **高价值扩展市场** | 仅提供带真实持久化逻辑与完整游戏内界面的 6 大系统级扩展：CG 鉴赏/回想/结局收集册、角色好感度进度、六格大图存档、玩家自定义名字、选择前自动存档、章节标题过场卡。 |
| **跨项目复用与多语言本地化** | 本地复用库支持跨项目安全导入角色/章节/场景/片段（自动匹配状态并清理失效素材）；三栏本地化工作台支持多语翻译进度、语言专属字体与图片替换。 |
| **内置 AI 创作助手** | 仅填 API Key 即用（预置 DeepSeek 并加密持久化），零外部程序依赖；上下文感知、折叠单行推理、合并操作记录、一键全局撤销。 |
| **数据安全与完成发布向导** | 原子写入保存屏障杜绝丢字；全局撤销/重做；2 分钟自动快照与关键节点里程碑（跨重启恢复）；连续完成向导打通检查直接修复、灵活试玩与多平台独立导出。 |

## 三、 典型零代码创作流程

1. **启程**：在首页点击「创建新游戏」，填写标题与分辨率，系统自动准备好运行环境与多语言字体。
2. **建角与备料**：批量拖入角色立绘图片自动建立角色与多表情，拖入背景与音乐素材统一归档。
3. **写故事与连路线**：在卡片视图中按回车连续编写对白，或切换纯文本视图高速写作；通过滑出抽屉插入背景转场、立绘变换、镜头氛围特效与分支选择；在选线流程图中审查分支、汇合与故事状态因果关系。
4. **即时排演与调优**：点选卡片或在右侧即时预览中实际点击选项、拖动时间轴、调节故事状态测试条件分支；按需在「游戏外观」定制对话框风格、在「扩展市场」开启鉴赏册与存档页。
5. **检查、试玩与交付**：进入「完成与发布」向导一键检查并直接修复潜在断链或缺失素材，启动实机试玩验证路线，最后一键打包导出可独立双击运行的 Windows 发行包。

## 四、 明确标记为“暂不开发专用 GUI”的能力边界

为保持零代码创作界面的简洁克制与极高易用性，以下底层高级开发能力**明确不开发专用可视化表单或拖拽编辑器**；创作者如有需要，可直接通过内置 **AI 创作助手**用自然语言在后台自动实现与维护，或由专业开发者在「高级模式」中直接编写脚本：

1. 任意 Python 代码逻辑的可视化编程界面；
2. 第三方插件开发、自定义引擎语句及任意插件配置的专用 GUI；
3. 任意或自定义界面语言（Screen Language）的 Figma 式完全自由拖拽 WYSIWYG 界面设计器；
4. 任意复杂循环及开放式程序控制流的 GUI 化；
5. 复杂列表、字典、对象等复杂数据结构的可视化表单；
6. 任意 ATL（动画与变换语言）及通用复杂动画时间轴编辑器；
7. LayeredImage（多层组合立绘语法）的通用可视化编辑器；
8. 3D Stage、Live2D、任意自定义 Shader、自定义 Displayable 的专用可视化编辑器；
9. 在软件安装包内捆绑或自动替用户下载安装 Web 构建支持包、RAPT、Android SDK、JDK 及应用商店签名环境（导出页面会以清晰中文如实说明原因，绝不伪造成功）。
